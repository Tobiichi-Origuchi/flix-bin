This is an __*unofficial*__ repo of [Flix](https://flix.center)

### Function

1. Get the Linux/Windows installation package for Flix and upload to release.
2. Generate `PKGBUILD` and Scoop manifest.

### Usage

#### Arch Linux

```bash
yay/paru -S flix-bin
```

#### Windows

```pwsh
scoop bucket add flix https://github.com/Tobiichi-Origuchi/flix
scoop install flix/flix
```
