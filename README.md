This is an __*unofficial*__ repo of [Flix](https://flix.center)

### Function

1. Get the Linux installation package for Flix and upload to release.
2. Generate `PKGBUILD`.

### Usage

#### Arch Linux

```bash
yay/paru -S flix-bin
```

#### Windows

```pwsh
scoop bucket add flix 
scoop install flix/flix
```
